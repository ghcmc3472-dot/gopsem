# 법무사 기출문제·학습자료 크롤링 소스 분석

조사일: 2026-09-13. 원격 환경의 네트워크 정책으로 실제 페이지 접속은 불가능했고,
웹 검색 결과에 노출된 URL 구조와 알려진 사이트 구성을 바탕으로 분석했다.
"확인 필요" 항목은 사용자 PC에서 `--dry-run` 으로 검증해야 한다.

## 소스별 상세

### 1. 박문각 법무사 (pmg.co.kr)
- 기출문제 게시판: `https://www.pmg.co.kr/user/bupmu/board/board_common.asp?bbsid=4282`
- 2차 자료실: `https://www.pmg.co.kr/user/bupmu/board/board_common.asp?bbsid=2488`
- 첨부파일은 `https://att.pmg.co.kr/EtcData/board/<bbsid>/<파일명>.pdf` 형태의 **정적 직링크**로 검색에 그대로 노출됨
  (예: 2017~2025년 1차 시험 총평 PDF, 31회 민법 총평 PDF).
- 게시글 중 `dn=scourt` 파라미터가 붙은 항목은 대법원 원본을 재게시한 것으로 보임.
- 크롤링 방식: 목록(`bbsid=4282`) 페이지네이션 → 게시글 → `att.pmg.co.kr` 링크 수집. 현재 크롤러의 첨부 판별 규칙으로 잡힘.

### 2. 합격의법학원 (judicial.lawschool.co.kr)
- 목록: `.../board/infomation/list.asp?field=12&mnNum=5&subMnNum=1&bbsCode=303`
- 확인된 게시글: 24회(num=79228), 26회(89689), 27회(94762), 30회(110578), 31회(115111) 1차 문제·정답가안,
  21년 1차 기출해설(95660), 22년 2차 기출해설(101222), 23년 2차 총평·해설(106126).
- 인코딩 EUC-KR, 클래식 ASP. 이미 크롤러 `lawschool` 소스로 등록되어 있음.
- `cpla.lawschool.co.kr`(bbsCode=3, field=2)에도 과목별 해설 게시글이 있어 소스 추가 가능.

### 3. 대법원 시험정보 (exam.scourt.go.kr) — 공식
- 법무사 안내: `https://exam.scourt.go.kr/wex/exinfo/info03.jsp`
- 기출문제 게시판 URL은 검색에 노출되지 않음(서블릿 `wex/EXSuperSvl?cmd=...` 구조로 추정).
  브라우저에서 메뉴 URL 확보 후 `--start-url` 로 지정 필요.
- 공공 저작물이라 이용 부담이 가장 적음. 우선순위 자체는 1순위지만 URL 미확인이라 난이도 "보통".

### 4. 법무사단기 (bupmu.conects.com)
- 시험총평&해설: `https://bupmu.conects.com/exam_info/bbs_library/lists/exam_info_data`
- 과목별 해설: `https://bupmu.conects.com/free_data/board_exam/main`
- 게시글: `.../bbs_library/view_m?document_idx=<id>` (예: 3064156, 2076492, 2076420)
- 커넥츠 계열은 일부 자료가 회원 로그인 후 열람. 페이지가 JS 로 그려지는지 확인 필요.

### 5. 공기출 (0gichul.com)
- 연도별 URL: `https://0gichul.com/y2025/130911268` (2025 법무사 전과목 문제 정답)
- 공무원·전문자격 기출을 연도별로 모아둔 사이트. 법무사 섹션 존재. 상업 사이트라 robots.txt·이용약관 확인 후 저속 크롤링.

### 6~9. 카페·CBT·서점·협회
- 다음 카페 자료(`m.cafe.daum.net/lee-minso`, `afterlawschool`)는 가입·로그인 필요, 개인 저작물 포함 → 자동 수집 부적절.
- CBT 문제은행(newbt.kr, cbtnote.com, comcbt.com, kinz.kr, cbtbank.kr)은 국가기술자격·공무원 위주이며 법무사 포함 여부 확인 안 됨. 문제 데이터가 JS/API 로 로드되어 단순 HTML 크롤링으로는 어렵다.
- 교보문고·예스24는 유료 해설집 상품 페이지만 있어 대상 아님. 대한법무사협회는 시험 안내만 제공.

## 크롤링 시 유의사항
- 대법원 자료는 공공누리 대상이 아닐 수 있으나 시험문제 공개 자료로 개인 학습 목적 수집은 통상 문제 없음.
- 학원 자료(총평·해설)는 학원 저작물이다. 개인 학습용 보관까지만 하고 재배포하지 않는다.
- 요청 간격 1초 이상(`--delay`), User-Agent 명시, robots.txt 준수.

## 크롤러 반영 현황
1. [완료] `pmg` 소스 추가: 목록 `bbsid=4282`, `2488`. 페이지 파라미터는 목록 페이지에서 자동 감지.
2. [완료] `--kind {1cha,2cha,all}` 옵션 추가. 저장 경로에 `1차/2차/기타` 하위 폴더 반영.
3. [예정] `lawschool` 소스에 `cpla.lawschool.co.kr` 과목별 해설 게시판 추가.
4. [예정] `conects` 소스: `document_idx` 목록 파싱, 로그인 필요 시 건너뜀.
